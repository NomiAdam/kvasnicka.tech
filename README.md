# kvasnicka.tech

Adam Kvasnička’s personal website. Plain HTML and CSS, with no JavaScript, dependencies, or build step.

English lives at `/en/` (and the root); Czech lives at `/cs/`. Each page includes a language switch and alternate-language metadata. Update the three HTML files together when editing shared content.

GitHub Pages publishes the root of `main`. Push changes to deploy. `CNAME` sets the custom domain to `kvasnicka.tech`.

For a local preview, run `python3 -m http.server 8000` and open http://localhost:8000.
